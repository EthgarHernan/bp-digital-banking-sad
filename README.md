# BP Digital Banking Platform — SAD

Documento de Arquitectura de Software para una plataforma de banca digital orientada a una entidad financiera ecuatoriana.

## Entregable

- Documento principal: `BP_Digital_Banking_Platform_SAD_Edgar_Changoluisa.pdf`

## Contenido principal

El documento incluye:

- Modelo C4 Nivel 1: Contexto
- Modelo C4 Nivel 2: Contenedores
- Modelo C4 Nivel 3: Componentes principales
- Decisiones arquitectónicas clave
- Seguridad, autenticación OAuth2/OIDC, cumplimiento LOPDP y auditoría
- Vista de despliegue en AWS
- Alta disponibilidad, recuperación ante desastres, monitoreo y costos

## Enfoque arquitectónico

La solución prioriza un diseño pragmático y evolutivo: monolito modular con servicios extraídos solo donde existe una justificación clara, evitando complejidad innecesaria para el MVP.
